# Global instructions

## Code comments

Do not add code comments. Write self-explanatory code instead. Only add comments when I explicitly ask for them, and in that case only where I asked.

This also means: do not add comments when editing existing code, and do not re-add comments that were removed. Leave comments that are already in the codebase alone unless the change makes them wrong.

## Git commits

Never add yourself as a commit co-author. Do not append `Co-Authored-By: Claude ...` or any similar attribution trailer to commit messages, and do not add "Generated with Claude Code" footers to commits.
